# Contributing to qsiprep

Contributions are welcome. Please see the [guidelines for contributing to NiPreps projects](https://www.nipreps.org/community/CONTRIBUTING/) and follow those here.

Before opening a pull request, please read our [guidelines for contributing](https://qsiprep.readthedocs.io/en/latest/developers.html#guidelines-for-contributing).
In short: open or comment on an issue first and wait for a developer to welcome a pull request,
report honestly how much of your contribution an LLM drafted,
and check the boxes in the pull request template, which a CI check requires.
